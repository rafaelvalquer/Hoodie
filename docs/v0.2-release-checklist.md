# Hoodie V0.2 — checklist de release (RC → main)

Branch: `v0.2-release-candidate` (a partir de `v0.2-visual-diary`). Tudo abaixo depende de
alguém com acesso ao GitHub e de uma revisão artística humana.

## 1. Publicar a RC e fazer a CI rodar de verdade

```bash
git push -u origin v0.2-release-candidate
```

O push já dispara a workflow (`on.push` inclui `v0.2-*`). Depois abra o PR
`v0.2-release-candidate → main` (GitHub › Pull requests › New). Checks esperados:
`unit-tests`, `lint`, `assemble`, `instrumentation`. Nenhum merge com check vermelho.

Corrigido antes do primeiro run: `gradlew` não era executável no git (o Linux recusaria
com "Permission denied") e scripts agora são sempre LF (`.gitattributes`).

## 2. Proteger a main

Settings › Branches › Add rule para `main` (passo a passo e comando `gh api` em
[ci-branch-protection.md](ci-branch-protection.md)):

- Require a pull request before merging
- Require status checks: `unit-tests`, `lint`, `assemble`, `instrumentation`
- Require branches to be up to date
- Do not allow bypassing the above settings

## 3. Revisão artística manual (bloqueia a versão 0.2.0)

Os quatro `assets-source/hoodie/hoodie_*.aseprite` são a fonte da arte. A passada atual
(`"pass": "claude-v1"`) foi feita em código; falta uma pessoa revisar no Aseprite:

1. Abrir cada `.aseprite`, revisar WALK / IDLE / SLEEP / WORK (checklist em
   assets-source/hoodie/README.md), ajustar o que precisar.
2. `./gradlew :app:testDebugUnitTest -PexportArt=true --tests "*FinalArtExportTest*"`
3. Em `assets-source/hoodie/art-status.json` **e** na cópia em
   `app/src/main/assets/pixel/hoodie/art-status.json`: `"manualReview": true`,
   `"reviewedBy": "<nome>"`.
4. Pixel Lab › Sprites deve mostrar "Manual reviewed 100%" nos quatro grupos.

## 4. Versão 0.2.0

Só depois do passo 3 (o `ShippedSheetsValidationTest` reprova uma release com arte sem
revisão manual):

- `gradle.properties`: `HOODIE_VERSION_NAME=0.2.0` (e subir `HOODIE_VERSION_CODE`)
- `README.md`: `**Versão: 0.2.0**`

## 5. Merge

Com os quatro checks verdes no PR e a main protegida: merge do PR.
